# Int8 quantization of the service models

Generated by `pawmatch/quantize.py` from `results/quantization.json` (detector) and `results/dev/quantization_reid.json` (re-ID). Do not edit by hand. Commands, from the repository root:

    ./venv/bin/python -m pawmatch.quantize configs/dogfacenet.toml detector
    ./venv/bin/python -m pawmatch.quantize configs/dogfacenet.toml reid

The quantization settings were fixed before any held-out measurement, and nothing was chosen from these numbers. The service still runs the fp32 models. Accuracy cells show the value and its 95% bootstrap interval.

## Setup

- Apple M5, 24 GB RAM, PyTorch 2.14.1, CPU only, qnnpack engine, 4 threads. Quantized kernels have no MPS version, so fp32 is measured on the CPU too. torch.ao.quantization is deprecated in this PyTorch (torchao is the migration path), though it still runs.
- Size: serialized state_dict, MB = 10^6 bytes.
- Latency: batch 1, forward pass only, photo already decoded and transformed. 100 photos drawn with seed 0. Each run times every photo once after 10 untimed photos, over 5 runs with fp32 and int8 interleaved. p50 and p95 are over photos within a run; the table shows the median over runs.

## Detector

trained dog-head detector (pawmatch.headdet): Faster R-CNN, MobileNetV3-Large FPN. Code commit 214b233.

- int8: static int8 MobileNetV3 body and FPN (FX graph mode, default qnnpack settings); dynamic int8 box head Linear layers.
- Kept in fp32: FPN extra 1x1 stride-2 max pool (QNNPACK rejects 1x1 pooling), RPN head, RoIAlign, NMS, box decoding.
- Calibration: first 100 half A training photos in headdet.half_a_split order.
- Score threshold: 0.2, the service threshold, not re-selected for int8.

## Re-ID embedding model

dinov2_vits14, checkpoint none (frozen backbone): the model `[serve]` uses. Code commit 214b233.

- int8: dynamic int8 Linear layers (default settings).
- Kept in fp32: patch embedding conv, LayerNorm, attention softmax, GELU.
- Evaluation: Milestone 1 (pawmatch.evaluate), whole photo resized to 224 px with no detection. DogFaceNet test split: development data, looked at before (m1 and later results); nothing is chosen from it.
